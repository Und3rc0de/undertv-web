¿Ya tienes UnderTV? Actualiza así

La actualización se instala encima de la versión actual. No desinstales la app: podrías borrar sus datos.

  1. Busca la arquitectura que usaste al instalar UnderTV. Si no la recuerdas, ARM64 es la adecuada para la mayoría de celulares y TV Box recientes.
  2. Pulsa el botón de descarga correspondiente y espera a que termine. También puedes revisar el número de versión que aparece arriba.
  3. Abre la notificación de descarga o entra en Archivos / Mis archivos → Descargas y pulsa el APK.
  4. Si Android lo solicita, permite a tu navegador o administrador de archivos Instalar apps desconocidas. Vuelve atrás y pulsa Actualizar o Instalar.
  5. Cuando termine, pulsa Abrir. La app y sus datos deberían conservarse.
¿Dice “La aplicación no se instaló”? Comprueba que descargaste la misma arquitectura y que no borraste la versión anterior. Si persiste, la firma o el paquete instalado puede no corresponder con esta versión.

No hace falta crear una cuenta para descargar la APK desde esta página.

x86_64 · emulador Android

Para emuladores configurados como x86_64 y algunos dispositivos Android con procesador Intel. No corresponde a celulares ARM como Motorola o Samsung.

Descargar APK x86_64

La versión ARM64 es la recomendada para la mayoría de los usuarios. ARM32 y x86_64 se ofrecen para dispositivos específicos; no garantizan compatibilidad con cada fabricante o versión de Android.

▯ Instalar en celular o tablet

  1. Elige la APK adecuada y toca Descargar.
  2. Abre la notificación o el archivo en Descargas.
  3. Autoriza instalaciones desde esa fuente si Android pregunta.
  4. Confirma y, al finalizar, abre UnderTV.

▱ Instalar en Android TV o Google TV

  1. Descarga la APK en la TV con un navegador, o bájala en el celular y pásala a la TV mediante USB o una app de transferencia de archivos.
  2. En la TV, abre Archivos / File Manager → Descargas o el USB y selecciona el APK.
  3. Si aparece el aviso, activa Instalar apps desconocidas para ese administrador de archivos.
  4. Confirma la instalación; luego busca UnderTV en Apps.

Usa ARM64 en la mayoría de las TV actuales; usa ARM32 solo si la TV ejecuta Android de 32 bits.

Los nombres de los ajustes cambian según la marca. En Android TV / Google TV, puede estar en Ajustes → Apps → Acceso especial de apps → Instalar apps desconocidas.

Windows de escritorio

Versión portátil para Windows x64. Se distribuye como ZIP.

UnderTV para Windows x64

Compatible con Windows 10/11 de 64 bits. Descarga, extrae el ZIP y abre UnderTV.exe.

Descargar para Windows
  1. Primera instalación: extrae todos los archivos del ZIP en una carpeta y ejecuta UnderTV.exe.
  2. Para actualizar: cierra UnderTV, descarga y extrae el ZIP nuevo en una carpeta nueva; abre el nuevo UnderTV.exe. Conserva la carpeta anterior hasta confirmar que la nueva versión abre.

Para los reproductores integrados se necesita Windows 10 versión 1809 o posterior y Microsoft Edge WebView2 Runtime. Instalar WebView2 desde Microsoft.
